Objetivo:
Identificar las causas de los gastos imprevistos en la sala de endoscopía.

Proceso:

Trabajo en conjunto con el Jefe del área para definir los datos y tipos de datos necesarios a registrar.

Coordinación con el equipo para elegir la herramienta de trabajo: Excel, por ser la más accesible para todos los integrantes.

Registro manual de datos durante 3 meses.

Uso de funciones como IFERROR, IFBLANK y validaciones de datos para garantizar la calidad y consistencia del ingreso.

Transformación y normalización de los datos en Power BI, cargando el archivo .xlsx y aplicando limpieza y unificación de formatos.

No se aplicó modelado relacional, ya que los datos se registraron en una única tabla.

Resultados:

Se detectó una correlación entre la curva de aprendizaje del personal y las fechas de ruptura de los equipos.

A partir del análisis, se recomendó implementar capacitaciones específicas para los endoscopistas, reduciendo los costos por fallas.
