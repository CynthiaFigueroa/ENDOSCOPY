#Objetivo

Identificar las causas de los gastos imprevistos en la sala de endoscopía.

#Proceso

##Definición de datos

Trabajo conjunto con el Jefe del área para determinar qué datos eran necesarios registrar y sus tipos.

##Recolección de datos

Trabajo colaborativo con el equipo de la sala.

Se decidió utilizar Microsoft Excel, por ser la herramienta más comprendida por todos.

Registro manual de datos durante 3 meses.

##Limpieza y validación

Uso de funciones como IFERROR, IFBLANK y validaciones de datos para garantizar la consistencia y evitar errores de carga.

##Transformación de datos

Carga del archivo .xlsx en Power BI.

Normalización y transformación de los datos mediante el Editor de Consultas.

No se aplicó modelado relacional ya que los datos provenían de una única tabla.

#Resultados

Se observó una coincidencia entre la curva de aprendizaje del personal y las fechas de ruptura de los equipos.

A partir del análisis, se promovió la implementación de capacitaciones específicas para los endoscopistas.

Esta acción permitió reducir los gastos por fallas y mejorar la eficiencia operativa.

#Herramientas utilizadas

Microsoft Excel

Power BI

Funciones: IFERROR, IFBLANK, validación de datos

#Aprendizajes

Importancia de la limpieza y consistencia de los datos desde el origen.

Valor del trabajo colaborativo en proyectos de mejora de procesos.

Uso de Power BI para detectar patrones y relaciones no evidentes en los registros operativos.
